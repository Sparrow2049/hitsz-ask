# Screenshots go here

House rule 5: no live demo, screenshots are the demo. Before you submit,
run `npm run dev`, click through the app, and drop these in here (then
update the table in the root `README.md` if you rename any of them):

1. **home.png** — the landing page, showing both feature cards and the
   course list.
2. **course-hub.png** — a course page (`/courses/CS101`) with at least one
   resource and one question visible, to show the two features living
   side by side.
3. **ask-thread.png** — a question thread (`/ask/[id]`) with a senior's
   answer showing the "Senior" badge and the resolved state.
4. Optional but worth it: one screenshot of the "Add a resource" or "Ask a
   senior" form mid-fill, to prove the interactions actually work and
   aren't just static mockups.

Real screenshots, from your own machine, with your own name in the
identity badge — not placeholders. That's what makes "the screenshots
prove it actually runs" (room v) true.
